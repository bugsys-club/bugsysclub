# Bugsy's Social Club — site vitrine

Site bilingue (français / anglais) de Bugsy's Social Club, Bastos, Yaoundé.

- `build.py` : tous les textes du site (dictionnaire `TEXTES`). Modifier puis lancer `python3 build.py`.
- `index.html`, `en/index.html` : pages générées.
- `assets/style.css` : couleurs, polices, mise en page.
- `assets/img/` : photos.

Publication : GitHub Pages, branche `main`, dossier `/ (root)`.
